# 기합 (KIHAP) — 도장 수업 도구

태권도장 수업·운영·게임·대회 도구를 한 곳에 모은 웹앱(PWA)입니다. 빌드 과정 없이 정적 파일만으로 동작해요.

- **수업 도구**: 타이머 · 인터벌 · 스톱워치 · 주사위 · 랜덤 뽑기 · 토너먼트 · 반응 신호 · 폭탄 돌리기
- **도장 운영**: 출석 체크(번호·명단·QR·얼굴) · 원생 관리(회비·띠·출석 현황) · 월간 계획표 · 차량 운행표
- **운동 게임**: 탑 오르기 · 스킬 피구 · 모션 달리기 · 몸으로 말해요 · 운동 사다리
- **대회**: 스코어보드 · 품새 채점(공인·자유)

데이터는 지금은 각 기기 브라우저(localStorage)에만 저장돼요. 원생 관리 → 반·설정에서 백업 파일을 받아 두세요.

## 로컬에서 실행

```bash
python -m http.server 5173
```

브라우저에서 http://localhost:5173 을 열면 돼요. 카메라 기능(QR·얼굴·모션 달리기)은 https 주소(예: GitHub Pages)나 localhost 에서만 동작해요.
